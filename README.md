# Топливо Хелм: автообновление цен

Как это работает
- `index.html` — сайт. Каждые 20 секунд читает `prices.json` и обновляет список, если файл изменился.
- `scraper/scrape.mjs` — сборщик. Открывает страницы заправок из `scraper/stations.json`, находит цены и обновляет `prices.json`.
- `.github/workflows/update-prices.yml` — запускает сборщик каждые 30 минут. Если цены изменились, коммитит `prices.json`, и Netlify сам публикует новую версию.

Запуск
1. Загрузите папку в репозиторий на GitHub и подключите этот репозиторий к Netlify (команда сборки пустая, папка публикации `.`).
2. В GitHub откройте Settings, Actions, General, Workflow permissions и включите Read and write permissions.
3. Вкладка Actions, Update fuel prices, Run workflow. В логе видно, какие цены найдены.

Добавить заправку
В `scraper/stations.json` добавьте `{ "id": "...", "url": "..." }`. `id` должен совпадать с `id` в списке STATIONS внутри `index.html`.

Важно
- Сборщик не проверялся на реальных страницах. Если в логе пишет «цен на странице нет», у заправки на AutoCentrum нет цен или изменилась вёрстка. Прежние цены при этом остаются.
- Проверьте условия использования сайтов, с которых берёте данные. Не запускайте сборщик чаще раза в 15–30 минут.
- Пока `prices.json` пуст, страница показывает примерные цены с пометкой «пример».
